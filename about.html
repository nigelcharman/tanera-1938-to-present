About

This map overlays a 1938 map on top of the current map.

It covers Tanera Park and the surrounding area. The image gets a bit more distorted towards the edges and may be a few metres off.

How to use

  • Basemap — use the layers control (top-right on the map) to switch between map view (OpenStreetMap) and satellite view (Esri World Imagery).
  • Overlay — the slider sets opacity of the 1938 aerial (default 60%). Slide toward 0% to see only the modern basemap; toward 100% for the historical image.
  • Locate — tap to request location permission, show your position and accuracy circle, and follow as you move. Drag the map to pause follow; tap Locate again to recenter.

How we built it

A 1938 Retrolens aerial of the Tanera Park / Brooklyn area was rectified in Map Warper (map 114001) with control points on lasting street corners and roof edges. The warped result is served as XYZ tiles and drawn in Leaflet over OSM or Esri imagery, with the browser Geolocation API for on-site GPS. The website is stored in a GitHub repository and deployed to Netlify.
